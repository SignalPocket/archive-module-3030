# Printer Calibration Kit V3 — Fine Rail Fit

The 0.30, 0.35, and 0.40 mm-per-side channels were all reported loose. This set narrows the test range.

Reuse the rectangular slider you already printed. Print only:

- `rail_clearance_010.stl`
- `rail_clearance_015.stl`
- `rail_clearance_020.stl`

Use the same PLA profile as the previous test: 0.20 mm layers, four walls, and no supports.

Test from loosest to tightest: **0.20 → 0.15 → 0.10**. Do not force the slider into a channel. The winner should move with one finger, remain aligned, and show little or no sideways rattle.

The magnet and M2 screw tests are complete; do not reprint them.
